# Платный API для демонстрации краулера

7 ноября 2026 года, ветка `AI-only-solution`. Для демонстрации извлечения дат я бы выбрал Gemini 2.5 Flash с уточнённым правилом выбора даты и отключённым веб-поиском. Пополнять счёт на $10 для одного показа избыточно. Средняя тарифная стоимость обработки реальной новости составила $0,0020. На момент проверки шлюз предлагал пополнение от $1. [Тарифы Blackroute](https://blackroute.ironborn.cc/#pricing)

У обычной Flash все пять ошибок локальной 9B исправлены, появилась одна новая. В `garden-01` детский сад сообщил о создании открытки к 4 ноября. Flash подставила дату праздника, хотя день изготовления открытки неизвестен. Flash-Lite нашла все определимые даты, но также выдала день окончания приёма анкет за дату акции и дату из заголовка за дату события.

В краулере есть дополнительная проверка совпадения с алгоритмом. Сверка сохранённых предсказаний по этому правилу даёт для Flash 11 автоматически принятых дат и 12 направлений на ручную проверку. Для локальной 9B получается 7 и 15 соответственно. Остальные случаи — обоюдный отказ определить дату. На этой выборке автоматически принятые даты совпали с разметкой у обеих моделей.

Выборка зафиксирована до прогонов и содержит 12 школьных, 12 детсадовских и 6 искусственных текстов. Оценивалось точное совпадение даты или `null`. Разметку выполнил Codex, независимой сверки человеком пока нет. Каждый ответ получен один раз. Локальные числа взяты из сохранённых прогонов. Для облачных использовались те же тексты, системная инструкция, схема JSON, температура 0 и предел ответа 2048 токенов. Хеши выборки и инструкции совпали. Для облака оставлен режим рассуждения провайдера. Flash сообщила о 13 710 токенах рассуждения, которые входят в число выходных токенов. Каждый из 60 запросов завершился с `stop`, поле даты в исходном JSON во всех случаях совпало с результатом парсера. Каждый прогон шёл последовательно, два прогона частично совпали по времени. Облачная Qwen 235B из каталога вернула HTTP 404 на первом запросе и исключена из сравнения.

## Как ведёт себя штатный веб-поиск

Отдельно выполнены два запроса Gemini 2.5 Flash через формат запросов краулера с Google Search и штатной инструкцией для фактчекинга. В основной таблице использовалась уточнённая инструкция для дат. Веб-прогоны проверяют также изменение инструкции.

| Новость | Результат ручной проверки |
| --- | --- |
| Поздравление гимназии с Днём народного единства | Сведения о празднике и 4 ноября верны. Краулер получил дату события 4 ноября, хотя в новости нет мероприятия гимназии. В основном прогоне Flash на том же тексте вернула `null`. [Календарь Банка России](https://www.cbr.ru/other/holidays/) |
| «Атомный диктант» в магаданской гимназии №24 | Дату 21 сентября модель извлекла верно. Сведения об организаторах подтверждаются. Для статуса «подтверждено» у участия именно этой гимназии модель сослалась на публикацию о культурном центре Калуги и новость омской школы №13. Обе ссылки раскрыты и страницы прочитаны. Они относятся к другим учреждениям. Это основание оставить участие конкретной гимназии без независимого подтверждения. [Минпросвещения](https://edu.gov.ru/press/11983/shkolnikov-i-pedagogov-priglashayut-prinyat-uchastie-v-atomnom-diktante/) · [Калуга](https://www.kaluga-poisk.ru/news/obschestvo/atomnyy-diktant-proydyot-v-innovatsionnom-kulturnom-tsentre) · [Омск](https://sh-13-omsk-r52.gosweb.gosuslugi.ru/roditelyam-i-uchenikam/novosti/novosti-193_230.html) |

Поиск вернул ссылки в обоих ответах. Время составило 7,43 и 7,74 с. Два примера позволяют показать работу поиска и конкретную ошибку привязки источника к учреждению. Для оценки общей точности фактчекинга нужна отдельная размеченная выборка.
