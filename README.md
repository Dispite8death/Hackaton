# Контур

Аудит сайтов школ и детских садов. Команда «Одинокие одиночки», кейс «ИИ-краулер».

[Руководство пользователя](output/pdf/Руководство%20пользователя.pdf) · [Устройство системы, БД и API](output/pdf/Руководство%20разработчика.pdf)

В архиве для жюри распакуйте все файлы и откройте **Открыть Контур.html**. Для просмотра готовых результатов достаточно браузера. Полный проект запускается по инструкциям ниже.

## Запуск на Windows

1. Распакуйте проект целиком и дважды нажмите **[Запустить аудит.bat](Запустить%20аудит.bat)**.
2. При первом запуске оставьте окно открытым. Для установки Python и библиотек нужен интернет. Если Windows не может установить Python автоматически, установите Python 3.13 и снова нажмите тот же файл.
3. В браузере откроется [Контур](http://127.0.0.1:8765/). Оставьте окно запуска открытым на время работы. Для обычной остановки нажмите Ctrl+C в окне запуска.

## Запуск на Linux

В каталоге проекта выполните `sh "Запустить аудит.sh"`. Откроется тот же портал с двумя режимами. Для сервера без графического рабочего стола используйте `sh start.sh --headless` и откройте адрес `http://127.0.0.1:8765/` на этом компьютере. Порт можно задать параметром `--port`.

Нужны Python 3.11 или новее с поддержкой venv и шрифт DejaVu Sans или Liberation Sans для PDF. При первом запуске нужен доступ к пакетам Python. Скрипт использует Linux-окружение отдельно от Windows. Путь к готовому окружению можно передать в `KONTUR_VENV`.

- `sh start.sh --once` выполняет один цикл углублённого аудита по сохранённым лимитам и настройкам ИИ.
- `sh start.sh --loop` повторяет цикл с заданным в панели интервалом, пока работает процесс. Для остановки нажмите Ctrl+C.
- `sh start.sh --status` показывает состояние последнего цикла.
- `sh start.sh --install-browser` устанавливает Chromium для сборщика страниц, снимков и PDF. Выполните эту команду перед первым сбором на Linux, если Chrome или Edge отсутствуют.

Главная открывает два режима. Из каждого можно вернуться к выбору нажатием на «Контур».

## Как проверить учреждение

- **Алгоритмический аудит** открывает обзор. В разделе **Запуск** выберите одно или несколько учреждений по названию или адресу и нажмите **Проверить сайты**. После первого обхода можно повторить проверку сохранённых страниц. Раздел **Отчёты** показывает последнюю завершённую проверку каждого учреждения и выгружает выбранные строки в HTML и CSV. В **Разборе с ИИ** можно запросить сводку и план исправления для конкретного отчёта.
- **Сводный аудит** — откройте «Учреждения» или «Результаты проверок», задайте фильтры и нажмите на нужную строку. PDF можно скачать для всего реестра, текущей выборки или отмеченных учреждений. Этот режим использует собственный архив. Чтобы начать его наполнение, в **Настройки → Фоновое обновление архива** нажмите **Обновить одну партию сейчас без ИИ**. Размер партии и интервал задаются там же.
- **ИИ** по умолчанию выключен. Для объяснений и модельных проверок откройте **Настройки → Подключение к модели**, выберите работающий сервер LM Studio, Ollama или внешний OpenAI-совместимый API, укажите модель и включите использование. Для внешнего сервиса нужен собственный ключ. Ключ хранится в хранилище учётных данных ОС.

В **Настройки → Проверка выбранных учреждений** доступны одиночный и групповой запуск с поиском по названию или домену. Для свежего отчёта выберите **Загрузить и сразу проверить алгоритмами** либо **Загрузить, проверить алгоритмами и передать готовые вопросы ИИ**. Отдельно доступны загрузка и анализ сохранённых материалов. Нажмите **Проверить материалы и оценить время**. План показывает объём архива, недостающие материалы и число готовых вопросов. При нехватке материалов отчёт покажет, что удалось проверить и какие разделы требуют догрузки. Во время загрузки система может обнаружить дополнительные ссылки. Оценка времени ИИ по пробному текстовому запросу приблизительна, особенно для фотографий и многостраничных PDF.

### Если закрыли вкладку или остановили сервер

Задания выполняются на компьютере с сервером. Вкладку можно закрыть. На главной странице есть ссылки на состояние последних заданий. Подробности сводной проверки доступны в **Настройках**, экспресс-проверки и разбора с ИИ — в **Алгоритмический аудит → Запуск**. Там видны прошедшее время, текущий этап и выполненный объём. Оценка остатка появляется, когда есть замеры.

После остановки сервера откройте проект снова и нажмите **Продолжить незаконченный этап** в соответствующем режиме. SQLite хранит выбор учреждений, завершённые этапы и результаты. Повторная загрузка может ещё раз посетить сайт текущего учреждения. Записанные ответы сводного ИИ повторно используются для тех же материалов и профиля. Запрос, который модель уже приняла, но ответ на который не успел сохраниться, при продолжении может быть отправлен повторно. Новый ручной запуск в этом режиме заменяет задание, доступное для продолжения. Сохранённые страницы и отчёты остаются в архиве.

Фоновое обновление ведёт свою очередь. После прерывания следующая партия подбирает доступную работу по расписанию и лимитам. Файлы и страницы, срок временной блокировки которых ещё не истёк, могут попасть в более позднюю партию.

**Сохранить настройки подключения** сохраняет профиль в локальной базе. **Проверить ответ модели** отправляет тестовый запрос. При изменённом профиле кнопка предложит сохранить его и проверить. Сообщение об ошибке соединения тоже сохраняется с датой последней проверки. Для LM Studio запустите локальный API и проверьте имя модели и порт.

В сводном аудите переход с диаграммы сохраняет фильтры выборки. В дополнительных фильтрах «Кто проверил» можно выбрать алгоритм, ИИ или критерии, которые ещё не проверялись.

В меню **Скачать PDF → Настроить фильтры PDF** можно совместить список учреждений, тип учреждения, критерий, серьёзность, источник вывода и период. **По текущим фильтрам** скачивает готовый PDF. **По отмеченным с текущими фильтрами** дополнительно ограничивает его отмеченными строками.

### Единый список учреждений

Откройте **Настройки → Управление списком учреждений**. Можно добавить одно учреждение или импортировать файл UTF-8. Пример выбранного формата отображается рядом с кнопкой импорта.

- JSON принимает массив объектов с полями `name`, `kind`, `site_url`.
- CSV принимает заголовок `name,kind,site_url` с разделителем в виде запятой или точки с запятой.
- TXT принимает по одному учреждению на строку в виде `название & тип & ссылка`.

Типы — `school` и `kindergarten`, также подходят «школа» и «детский сад». Файл проверяется целиком. Повторный импорт того же адреса обновляет название и тип. Удаление из списка или очистка исключает учреждения из выбора и проверок в обоих режимах. Повторное добавление сайта восстанавливает связь с его историей.

Оба режима при первом запуске создают свои базы и импортируют из задания 40 школ и 40 детских садов. Результаты появятся после проверок. Сводный архив хранится в `search.sqlite3`, данные алгоритмического аудита — в `data/quick/`. Пути можно задать через `HACKATON_DB_PATH` и `HACKATON_QUICK_DIR`.

Для браузерных снимков сводного аудита нужен Chromium, Chrome или Edge. Если поддерживаемый браузер отсутствует, выполните `.venv\Scripts\python -m playwright install chromium` на Windows или `sh start.sh --install-browser` на Linux.
