# Контур · Аудит сайтов школ и детских садов

## Запуск на Windows

1. Распакуйте проект целиком и дважды нажмите **[Запустить аудит.bat](Запустить%20аудит.bat)**.
2. При первом запуске оставьте окно открытым. Для установки Python и библиотек нужен интернет. Если Windows не может установить Python автоматически, установите Python 3.13 и снова нажмите тот же файл.
3. В браузере откроется [Контур](http://127.0.0.1:8765/). Оставьте окно запуска открытым на время работы. Чтобы остановить приложение, закройте его.

В Linux выполните `sh start.sh` из корня проекта. Нужны Python 3.11 или новее с поддержкой venv и шрифт DejaVu Sans или Liberation Sans для PDF.

## Как проверить учреждение

- **Алгоритмический аудит** — выберите учреждение по названию, нажмите **Открыть учреждение → Проверить сайт**. Появятся балл, замечания и страницы, где они найдены. После первого обхода доступна повторная проверка сохранённых страниц. В разделе «Отчёты» можно скачать HTML и CSV. Правила, эталон фотографии и параметры обхода находятся в этом же режиме.
- **Сводный аудит** — откройте «Учреждения» или «Результаты проверок», задайте фильтры и нажмите на нужную строку. PDF можно скачать для всего реестра, текущей выборки или отмеченных учреждений. Этот режим использует собственный архив. Чтобы начать его наполнение, в **Настройки → Обновление всех источников** нажмите **Выполнить один цикл**. Размер партии и интервал задаются там же.
- **ИИ** по умолчанию выключен. Для объяснений и модельных проверок откройте **Настройки → Подключение к модели**, выберите работающий сервер LM Studio, Ollama или внешний OpenAI-совместимый API, укажите модель и включите использование. Для внешнего сервиса нужен собственный ключ. Ключ хранится в хранилище учётных данных ОС.

Оба режима при первом запуске создают свои базы и импортируют из задания 40 школ и 40 детских садов. Результаты появятся после проверок. Сводный архив хранится в `search.sqlite3`, данные алгоритмического аудита — в `data/quick/`. Пути можно задать через `HACKATON_DB_PATH` и `HACKATON_QUICK_DIR`.

Для браузерных снимков сводного аудита нужен Chromium, Chrome или Edge. Если поддерживаемый браузер отсутствует, выполните `.venv\Scripts\python -m playwright install chromium` на Windows или `.venv/bin/python -m playwright install chromium` на Linux.
