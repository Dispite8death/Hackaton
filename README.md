# Аудит сайтов школ и детских садов Магаданской области

В реестре 40 школ и 40 детских садов. В карточке учреждения собраны результаты проверок, ссылки на источники и пояснения к замечаниям. Уровень оценки и доля проверенных критериев показаны отдельно. Если доказательств недостаточно, отчёт указывает, какие материалы нужны для проверки.

## Запуск

На Windows с установленным Python 3 запустите [start.cmd](start.cmd). На Linux выполните `sh start.sh` из корня проекта. При первом запуске скрипт создаст виртуальное окружение и установит зависимости. Для PDF на Linux нужен шрифт DejaVu Sans или Liberation Sans.

Откроется [реестр](http://127.0.0.1:8765/). При первом запуске приложение создаёт `search.sqlite3` и импортирует список учреждений из документа задания. Снимки страниц и результаты проверок хранятся локально. Чтобы использовать другой архив, задайте путь в `HACKATON_DB_PATH` перед запуском.

## Презентация и отчёты

Выберите тип учреждения, уровень оценки, категорию проверки или критичность. Откройте карточку учреждения, чтобы показать конкретное замечание и его источник. В меню PDF доступны отчёты по всем учреждениям, текущей выборке и отмеченным организациям. Фильтры применяются к архивным данным. Просмотр сайта и экспорт PDF не запускают сбор.

## Сбор и обновление

В [локальной панели](http://127.0.0.1:8765/admin) можно запустить один цикл, выбрать интервал, глубину новостей и размеры партий, настроить модель, словари, допустимые внешние источники и хранение устаревших материалов. Циклы постепенно обрабатывают очередь. Для новых браузерных снимков установите Chromium командой `.venv\Scripts\python -m playwright install chromium` на Windows или `.venv/bin/python -m playwright install chromium` на Linux.

Расписание Windows включается в панели на выбранной машине. На Linux для периодической работы запустите `.venv/bin/python -m Engine.audit_worker --loop` после инициализации базы. Второй локальный порт, `127.0.0.1:8766`, предназначен для публикации витрины через прокси. Панель управления доступна на первом порту.
