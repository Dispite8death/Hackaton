      Вкладку можно закрыть. Чтобы продолжить после остановки сервера, вернитесь сюда. Система повторит только незаконченный этап выбранного учреждения. Новый запуск заменяет задание, доступное для продолжения.
        

        

        Фоновое обновление архива
        За один запуск система берёт часть сайтов из очереди, затем обрабатывает дополнительные страницы, вложения и публикации. Число сайтов, файлов и дополнительных страниц задаётся на один запуск для всего реестра. Лимит основных страниц, число переходов и период новостей также действуют при ручной загрузке выбранного сайта.
